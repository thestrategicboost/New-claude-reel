# Skill montage réels Instagram pour Claude Code

Un skill pour Claude Code qui monte tes réels Instagram **dans ta propre charte** (couleurs, polices, sous-titres) :
tu envoies ta vidéo brute, Claude coupe les blancs, ajoute les sous-titres et les effets au moment où tu les dis.

Par **Maé · @thestrategicboost.fr**

## Installation

Dans Claude Code (claude.ai/code), colle :

> Installe le skill de montage vidéo qui se trouve sur ce dépôt GitHub public :
> github.com/thestrategicboost/skill-montage-reels. Copie son dossier « video-edit » dans « .claude/skills/ »
> de mon dépôt, puis lance sa configuration.

Au premier lancement, le skill te demande ta charte (tes couleurs, tes polices, ton style de sous-titres).

Le guide pas à pas complet est envoyé en DM : commente **MONTAGE** sous la vidéo.
