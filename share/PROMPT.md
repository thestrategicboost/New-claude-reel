# Monter ses réels avec Claude : le prompt

## ① Une seule fois, dans Claude Code (claude.ai/code)

Installe le skill de montage vidéo « video-edit » depuis ce lien : https://github.com/thestrategicboost/skill-montage-reels.
Copie le dossier `video-edit` dans `.claude/skills/` de mon projet, puis lance sa configuration.

Voici ma charte pour qu'il l'enregistre :
- Mon prénom : …
- Mon compte Instagram : @…
- Mes couleurs (codes couleur si je les ai) : couleur principale …, couleur foncée …, couleur d'accent …
- Ma police pour les titres : … / ma police pour le texte : …
- Mes sous-titres : un mot à la fois, en blanc avec une ombre noire (ou décris ton style)
- Le look que je veux : naturel / rosé / chaud / sombre
- Ce que je ne veux jamais : …

Quand tout est prêt, écris-moi « PRÊT » et explique-moi en une phrase comment t'envoyer mes vidéos.

## ② À chaque nouvelle vidéo

/video-edit
Ma vidéo brute est dans mon Google Drive, elle s'appelle « … ».
Mon inspiration (si j'en ai une) : « … ».
Monte-la dans ma charte. Écoute ce que je dis et mets les effets au moment où je les dis
(par exemple : quand je dis « mur de réels », un mur de mes réels derrière moi).
Coupe les blancs et les prises ratées. Garde ma vitesse normale.
Fais-moi d'abord un test, je te donnerai mes retours avant la version finale.
